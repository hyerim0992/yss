YSS 관리자 UI / Eclipse 경로 최종 안내
======================================
기준 프로젝트: 최종 JSP 템플릿 구조
목적: 관리자 담당자가 Eclipse에서 화면/JS/Controller 파일을 정확히 찾고 기능별로 분리 작업하기 위한 안내

[0] 관리자 경로 핵심
--------------------
Context Root : yss
기본 주소    : http://localhost:8080/yss

관리자 공통 화면 이동 Controller
src/main/java/com/yss/controller/admin/HomeManageController.java

관리자 JSP 루트
src/main/webapp/WEB-INF/views/admin/

관리자 CSS 루트
src/main/webapp/dist/css/admin/

관리자 JS 루트
src/main/webapp/dist/js/admin/

build/classes는 수정하지 않습니다.

[3] 회원/상품/물류/통계 JSP 작성 구조
------------------------------------
아래 네 화면은 예전 데이터 JS가 화면 구조를 만드는 방식이 아니라 JSP에 직접 HTML이 있습니다.

src/main/webapp/WEB-INF/views/admin/member/main.jsp
src/main/webapp/WEB-INF/views/admin/product/main.jsp
src/main/webapp/WEB-INF/views/admin/logistics/main.jsp
src/main/webapp/WEB-INF/views/admin/status/main.jsp

JSP 내부에 직접 존재하는 것
- 페이지 제목
- 탭 버튼
- 검색창
- 필터 select/date input
- table / thead / tbody
- 샘플 데이터 행
- 등록/수정 입력폼 template
- 행 추가용 template
- 페이징 버튼 template

JS
src/main/webapp/dist/js/admin/list.js

JS 담당
- 탭 전환
- 검색/필터/초기화
- 체크박스 전체 선택
- 선택 삭제 / 행 삭제
- CSV 저장
- 등록/수정 모달 열기
- JSP template 복제 및 값 입력
- 페이징

목록 데이터 연동 시 JSP의 샘플 행을 기준으로 직접 반복 출력 코드로 바꿉니다.

[8] Git 충돌 방지
-----------------
충돌 위험이 높은 공통파일
- src/main/webapp/WEB-INF/views/admin/layout/header.jsp
- src/main/webapp/WEB-INF/views/admin/layout/left.jsp
- src/main/webapp/WEB-INF/views/admin/layout/modal.jsp
- src/main/webapp/dist/js/admin/list.js
- src/main/webapp/dist/js/admin/common.js
- src/main/webapp/dist/css/admin/common.css
- src/main/webapp/dist/css/admin/list.css
- src/main/webapp/dist/css/admin/modal.css
- src/main/webapp/dist/css/admin/static-list.css

회원/상품/물류/통계 main.jsp는 화면별로 분리되어 있으므로 각 담당자가 자기 JSP 위주로 작업합니다.
고객지원도 inquiry/faq/notice/qna 폴더로 분리되어 있습니다.

작업 원칙
1. 시작 전 git pull
2. 자기 담당 JSP 위주로 수정
3. 공통 JS/CSS 수정이 필요하면 팀에 먼저 공유
4. 작은 단위로 commit
5. merge 후 해당 화면 실행 테스트


[9] 관리자 권한 확인
--------------------
파일
src/main/java/com/yss/filter/LoginFilter.java

관리자 URL 접근 시 로그인 SessionInfo의 role이 5 미만이면 /member/noAuthorized 로 이동합니다.
현재 프로젝트에서 해당 Mapping/JSP 구현 여부를 관리자 로그인 테스트 전에 확인합니다.
