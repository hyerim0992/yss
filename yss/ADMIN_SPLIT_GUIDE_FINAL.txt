[2] 관리자 JSP 전체 실제 구조
-----------------------------

├─ member/main.jsp             회원관리
├─ product/main.jsp            상품관리
├─ logistics/main.jsp          물류관리
├─ support/main.jsp            고객지원
├─ status/main.jsp             통계현황

├─ layout/

│  ├─ left.jsp                 관리자 왼쪽 메뉴
│  ├─ listContent.jsp          회원/상품/물류/지원/통계 공통 목록 본문
│  ├─ modal.jsp                등록/수정/답변/삭제 공통 모달

주의:

공통 구조 변경이 꼭 필요할 때만 팀과 공유 후 공통파일을 수정합니다.


[7] 관리자 백엔드 구현 시 생성/수정 위치
----------------------------------------
현재 화면 이동 Controller
src/main/java/com/yss/controller/admin/HomeManageController.java

현재는 관리자별 Service/Mapper가 따로 만들어져 있지 않습니다.
DB 연결 작업을 시작할 때 기존 회원 구조를 참고해 아래 위치에 기능별 파일을 추가하면 됩니다.
[아래 파일명은 권장 예시이며 yss(4)에 현재 존재한다는 뜻이 아닙니다.]

예: 관리자 상품관리
Controller : src/main/java/com/yss/controller/admin/ProductManageController.java
Service    : src/main/java/com/yss/service/ProductService.java
ServiceImpl: src/main/java/com/yss/service/ProductServiceImpl.java
Mapper     : src/main/java/com/yss/mapper/ProductMapper.java
Mapper XML : src/main/webapp/WEB-INF/classes/mybatis/mapper/ProductMapper.xml
DTO        : src/main/java/com/yss/dto/ProductDTO.java

예: 관리자 물류관리
Controller : src/main/java/com/yss/controller/admin/LogisticsManageController.java
Service    : src/main/java/com/yss/service/LogisticsService.java
Mapper     : src/main/java/com/yss/mapper/LogisticsMapper.java
Mapper XML : src/main/webapp/WEB-INF/classes/mybatis/mapper/LogisticsMapper.xml

중요:
이 프로젝트의 Mapper XML 실제 기준 폴더는
src/main/webapp/WEB-INF/classes/mybatis/mapper/
입니다.


[8] 관리자 로그인/권한 경로 주의
--------------------------------
파일:
src/main/java/com/yss/filter/LoginFilter.java

현재 동작:
- URL에 admin이 포함되고
- 로그인 SessionInfo의 role이 5 미만이면
- /member/noAuthorized 로 redirect

현재 문제:
yss(4) Controller에는 /member/noAuthorized Mapping이 없습니다.
따라서 관리자 권한 테스트를 시작하기 전에
1) noAuthorized Controller/JSP를 만들거나
2) LoginFilter의 redirect 목적지를 기존 화면으로 변경해야 합니다.

또한 관리자 URL은 로그인하지 않은 상태에서는 LoginFilter에 의해
/member/login 으로 이동합니다.


[9] Git 작업 시 관리자 충돌 방지
--------------------------------
충돌 위험이 높은 공통파일
- src/main/webapp/WEB-INF/views/admin/layout/listContent.jsp
- src/main/webapp/WEB-INF/views/admin/layout/modal.jsp
- src/main/webapp/WEB-INF/views/admin/layout/header.jsp
- src/main/webapp/WEB-INF/views/admin/layout/left.jsp
- src/main/webapp/dist/js/admin/list.js
- src/main/webapp/dist/js/admin/common.js
- src/main/webapp/dist/css/admin/common.css
- src/main/webapp/dist/css/admin/list.css
- src/main/webapp/dist/css/admin/modal.css

화면별로 분리되어 충돌이 비교적 적은 파일
- data/member.js
- data/product.js
- data/logistics.js
- data/support.js
- data/status.js
- admin/member/main.jsp
- admin/product/main.jsp
- admin/logistics/main.jsp
- admin/support/main.jsp
- admin/status/main.jsp

작업 원칙
1. 시작 전 git pull
2. 공통파일 수정이 필요하면 팀에 먼저 공유
3. 자기 화면 data/*.js 위주로 먼저 작업
4. 작은 단위로 commit
5. push 전 최신 branch를 다시 반영하고 충돌 확인


[10] Eclipse에서 관리자 화면 확인 순서
--------------------------------------
1. yss 프로젝트 우클릭 -> Refresh(F5)
2. Project -> Clean -> yss
3. Tomcat Stop -> Start
4. 관리자 권한(role 5) 계정으로 로그인
5. 아래 URL 확인

http://localhost:8080/yss/admin
http://localhost:8080/yss/admin/member
http://localhost:8080/yss/admin/product
http://localhost:8080/yss/admin/logistics
http://localhost:8080/yss/admin/support
http://localhost:8080/yss/admin/status

※ Context Root를 Eclipse Servers > Modules에서 따로 변경했다면 /yss 부분만 변경됩니다.
