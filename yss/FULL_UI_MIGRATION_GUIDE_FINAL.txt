YSS 전체 UI / Eclipse 경로 최종 안내
=====================================
기준 프로젝트: 최종 JSP 템플릿 구조
목적: 팀원이 Eclipse에서 실제 수정 파일을 바로 찾고, JSP -> Controller -> Service -> Mapper 흐름으로 연습하기 위한 경로 안내

[0] 가장 먼저 기억할 것
-----------------------
1. 직접 수정할 소스는 yss/src/main/... 아래입니다.
2. yss/build/classes/... 는 Eclipse 컴파일 결과물이므로 직접 수정하지 않습니다.
3. JSP 화면은 src/main/webapp/WEB-INF/views/... 에 있습니다.
4. CSS / JS / 이미지는 src/main/webapp/dist/... 에 있습니다.
5. WEB-INF/views 아래 JSP는 브라우저에서 JSP 경로로 직접 호출하지 않고 Controller URL로 들어갑니다.
6. Context Root는 yss 입니다. 기본 주소는 http://localhost:8080/yss/... 형태입니다.
   Tomcat 포트를 9090으로 설정했다면 http://localhost:9090/yss/... 로 사용합니다.
7. jQuery는 4.0.0, Bootstrap은 5.3.8 기준입니다.

현재 UI 작성 원칙
- JSP : 화면 HTML, 테이블/카드/폼/샘플 데이터, template 마크업
- JavaScript : 클릭, 탭, 필터, 정렬, 모달, 수량, 슬라이드 등 동작
- DB 연결 연습 시 : JSP의 샘플 반복 HTML을 직접 c:forEach / EL 출력으로 교체

[5] JSP 템플릿 연습 방법
------------------------
현재 목록/상품 카드 화면에는 화면 확인용 샘플 HTML이 JSP에 직접 들어 있습니다.
백엔드 구현 시 샘플 한 행 또는 한 카드를 기준으로 다음을 직접 연습합니다.

Controller
  -> Service
  -> Mapper
  -> DB 조회
  -> Controller에서 List/DTO를 request(ModelAndView)에 저장
  -> JSP에서 반복 출력 및 조건 처리

예: 상품검색
src/main/webapp/WEB-INF/views/product/search.jsp 안의 반복되는 article.search-product-card 부분을
나중에 직접 반복 출력 구조로 교체합니다.

예: 상품카테고리
src/main/webapp/WEB-INF/views/product/category.jsp 안의 반복되는 data-category-product 카드 부분을
나중에 직접 반복 출력 구조로 교체합니다.

JavaScript 파일에는 화면 전체 HTML 문자열을 작성하지 않습니다.

   src/main/webapp/WEB-INF/classes/mybatis/mapper/ 입니다.


[7] Controller에서 JSP 연결 원칙
-------------------------------
예)
return new ModelAndView("product/detail");

실제 JSP
/WEB-INF/views/product/detail.jsp

브라우저에서 WEB-INF/views 경로를 직접 입력하지 않습니다.

redirect 예)
return new ModelAndView("redirect:/main");
